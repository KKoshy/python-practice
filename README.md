Each folder covers one language fundamental, so you can run and read the examples topic by topic.

## Repository Structure

| Folder | Topic |
| --- | --- |
| [`variables/`](variables) | Variable declaration, assignment, naming conventions, scope |
| [`data_types/`](data_types) | Numbers, strings, lists, tuples, sets, dictionaries, type conversion |
| [`control_flow/`](control_flow) | Conditionals, `for` / `while` loops, `break` / `continue` |
| [`functions/`](functions) | Defining functions, arguments, return values, lambdas |
| [`oops/`](oops) | Classes, objects, inheritance, encapsulation, polymorphism |
| [`error_handling/`](error_handling) | `try` / `except` / `finally`, raising and handling exceptions |
| [`file_handling/`](file_handling) | Reading and writing files, context managers |

## Getting Started

**Prerequisites:** Python 3.8 or newer.

```bash
# Clone the repository
git clone https://github.com/KKoshy/python-practice.git
cd python-practice

# Run any snippet
python <folder>/<script>.py
```

## How to Use

- Start with `variables/` and `data_types/`, then move on to `control_flow/` and `functions/`.
- Read a snippet, predict its output, then run it to check.
- Modify the examples and break them on purpose to see what happens.
